# 🚀 Visual Experiments

🌐 **Live Demo:**  
https://alexisontheway.github.io/visual-experiments/

A curated collection of interactive and visually engaging web-based simulations built using **HTML, CSS, and JavaScript**. This project explores particle systems, physics-inspired motion, and dynamic rendering techniques.

---

## ✨ Projects Included

### 🧠 Neural Network Visualizer
Interactive particle network simulation with dynamically connected nodes and animated edges.

🔗 Live:  
https://alexisontheway.github.io/visual-experiments/neural-network-visualizer/

---

### 🌌 Orbital Gravity Simulator
Physics-inspired system demonstrating particles orbiting around a central gravitational force.

🔗 Live:  
https://alexisontheway.github.io/visual-experiments/orbital-gravity-simulator/

---

### 💥 Particle Explosion Sandbox
Interactive particle system allowing users to generate and control explosion-based animations.

🔗 Live:  
https://alexisontheway.github.io/visual-experiments/particle-explosion-sandbox/
